## Local rules

- The tool card for this wiki lives in the hub, not in this repo. This is a
  public repository and holds nothing hub-specific.
- Output byte-identity with Perl Trim Galore v0.6.11 is a tested invariant for
  the core flag paths. A page describing one of those paths states the
  behaviour the invariant pins, not just the current code's shape.
- Line numbers are never cited. Name the function, or the branch condition
  when no function owns the subject.
